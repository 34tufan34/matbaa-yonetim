# Patrol Ambalaj Baskı Takip — Android

Bu Android kabuğu canlı Sites uygulamasını güvenli bir WebView içinde açar.

- PDF, JSON ve fotoğraf seçimi desteklenir.
- Kamera ile fotoğraf eklenebilir.
- Rapor yazdırma / PDF akışı Android yazdırma ekranına bağlanır.
- JSON yedekleri Android İndirilenler klasörüne kaydedilir.
- Uygulama verileri cihazdaki WebView depolamasında saklanır.
- İlk açılıştan sonra web önbelleği ve servis çalışanı çevrimdışı kullanımı destekler.

Derleme: `gradle --no-daemon :app:assembleRelease`
