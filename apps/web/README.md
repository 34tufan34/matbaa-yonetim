# Matbaa Yönetim Sistemi — HTML V1

Tarayıcı üzerinde çalışan ilk prototip.

## Modüller
- Komuta Merkezi
- Müşteri Yönetimi
- İş Emirleri
- Üretim Takibi
- Makine Yönetimi

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. Veriler bu sürümde tarayıcının `localStorage` alanında saklanır.

Bu yapı ileride backend/veritabanı ve Android APK paketlemesine uygun şekilde geliştirilecektir.
